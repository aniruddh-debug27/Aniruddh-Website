Python Conditions (if, elif, else)

Conditions ka use program mein decision lene ke liye hota hai. Python mein mainly if, elif aur else use hote hain.

1. if Statement

age = 18

if age >= 18:
    print("You can vote")

Output

You can vote

2. if else

age = 15

if age >= 18:
    print("Adult")
else:
    print("Minor")

Output

Minor

3. if elif else

marks = 75

if marks >= 90:
    print("Grade A")

elif marks >= 60:
    print("Grade B")

else:
    print("Fail")

Output

Grade B
