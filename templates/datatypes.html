Python Data Types

Python me data ko store karne ke liye different types ke data types use hote hain.

1. Integer (int)

Whole numbers ko integer bolte hain.

age = 17 print(age)

2. Float

Decimal numbers ko float bolte hain.

price = 99.99 print(price)

3. String (str)

Text ko string bolte hain.

name = "Aniruddh" print(name)

4. Boolean (bool)

True ya False value ko boolean bolte hain.

is_student = True print(is_student)

5. List

Multiple values store karne ke liye list use hoti hai.

cars = ["BMW","Audi","Mercedes"] print(cars)

6. Dictionary (dict)

Key aur value ke form me data store hota hai.

student = { "name":"Aniruddh", "age":17 } print(student)

Summary

Python ke main data types hain: int, float, str, bool, list, tuple, set aur dictionary.
