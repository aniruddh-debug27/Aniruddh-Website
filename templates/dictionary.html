Python Dictionaries

A dictionary stores data in key-value pairs.

Example

student = {
    "name": "Aniruddh",
    "age": 17,
    "course": "Python"
}

print(student)
print(student["name"])

Output

{'name': 'Aniruddh', 'age': 17, 'course': 'Python'}
Aniruddh

Important Points

  • Stores data as key-value pairs.
  • Keys must be unique.
  • Values can be duplicated.
  • Dictionaries are mutable (can be changed).
