Python Functions

Function ek reusable block of code hota hai. Agar ek hi code ko baar-baar use karna ho to Function banaya jata hai.

Creating a Function

def greet():
    print("Hello World")

greet()

Output

Hello World

Function with Parameters

def greet(name):
    print("Hello", name)

greet("Aniruddh")

Output

Hello Aniruddh

Function with Return Value

def add(a, b):
    return a + b

result = add(10, 20)

print(result)

Output

30

Why Use Functions?

  • Code Reusability
  • Easy to Read
  • Easy to Debug
  • Reduces Repetition
