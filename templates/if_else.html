Python If Else

Python me decision lene ke liye if, elif aur else statements ka use hota hai.

1. If Statement

Agar condition true hoti hai to if ke andar ka code run hota hai.

age = 18

if age >= 18:
    print("You can vote")

2. If Else Statement

Agar condition false ho jaye to else ka code run hota hai.

age = 15

if age >= 18:
    print("Adult")
else:
    print("Minor")

3. Elif Statement

Multiple conditions check karne ke liye elif use hota hai.

marks = 80

if marks >= 90:
    print("A Grade")
elif marks >= 60:
    print("B Grade")
else:
    print("C Grade")

4. Nested If

Ek if ke andar dusra if use kar sakte hain.

age = 20

if age >= 18:
    if age <= 60:
        print("Allowed")
Remember:
if → condition check karta hai
elif → extra condition check karta hai
else → jab koi condition true na ho
