Python Input and Output

Python me user se data lene ke liye input() aur output dikhane ke liye print() function use hota hai.

Python Output

Output dikhane ke liye Python me print() function ka use karte hain.

print("Hello Python")

print(5 + 10)

Python Input

Input function user se information leta hai.

name = input("Enter your name: ")
print(name)

Taking Number Input

Agar number lena ho to int() ka use karte hain.

age = int(input("Enter your age: "))
print(age)

Example Program

name = input("Name: ")
age = int(input("Age: "))

print("My name is", name)
print("My age is", age)
Remember:
input() → User se data leta hai
print() → Screen par output dikhata hai

Summary

Python me input aur output ka use programs ko interactive banane ke liye hota hai.
