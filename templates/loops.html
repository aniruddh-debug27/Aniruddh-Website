Python Loops

Loop ka use kisi code ko baar-baar execute karne ke liye hota hai. Python mein do main loops hote hain:

  • for Loop
  • while Loop

1. for Loop

for loop ka use sequence (list, string, range) ke saath hota hai.

for i in range(5):
    print(i)

Output

0
1
2
3
4

2. while Loop

while loop tab tak chalta hai jab tak condition True hoti hai.

count = 1

while count <= 5:
    print(count)
    count += 1

Output

1
2
3
4
5

Infinite Loop

Agar condition kabhi False na ho to loop kabhi nahi rukta. Isse Infinite Loop kehte hain. 

while True:
    print("Hello")

Note: Real projects mein Infinite Loop ko carefully use karna chahiye.
