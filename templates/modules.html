Python Modules

A module is a file that contains Python code such as functions, variables, and classes that you can reuse in other programs.

Import a Module

import math

print(math.sqrt(25))
print(math.pi)

Output

5.0
3.141592653589793

Import Specific Function

from math import factorial

print(factorial(5))

Output

120

Important Points

  • Modules help reuse code.
  • Use import to load a module.
  • You can import the whole module or specific functions.
  • Python has many built-in modules like math, random, datetime, and os.
