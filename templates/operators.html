Python Operators

Operators ka use Python me calculations aur comparisons karne ke liye hota hai.

1. Arithmetic Operators

Mathematical operations ke liye use hote hain.

a = 10 b = 5 print(a + b) print(a - b) print(a * b) print(a / b)

2. Comparison Operators

Do values ko compare karne ke liye.

x = 10 y = 20 print(x == y) print(x < y) print(x > y)

3. Assignment Operators

Value assign karne ke liye.

x = 5 x += 2 print(x)

4. Logical Operators

Multiple conditions check karne ke liye.

age = 18 print(age > 10 and age < 30)

5. Membership Operators

Check karta hai ki koi value list ya string me hai ya nahi.

cars = ["BMW","Audi"] print("BMW" in cars)

Summary

Python ke main operators:
Arithmetic, Comparison, Assignment, Logical aur Membership Operators.
