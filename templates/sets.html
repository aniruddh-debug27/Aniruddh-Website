Python Sets

A Set is a collection used to store multiple items in one variable.

Example

fruits = {"Apple", "Banana", "Mango"}

print(fruits)

fruits.add("Orange")

print(fruits)

Output

{'Apple', 'Banana', 'Mango'}

{'Apple', 'Banana', 'Mango', 'Orange'}

Important Points

  • Sets are unordered.
  • Sets do not allow duplicate values.
  • Sets are mutable (can be changed).
  • Items are accessed using loops, not indexes.

Common Methods

fruits.add("Orange")
fruits.remove("Banana")
fruits.clear()
