Python Tuples

A tuple is a collection used to store multiple items in a single variable.

Example

fruits = ("Apple", "Banana", "Mango")

print(fruits)
print(fruits[0])

Output

('Apple', 'Banana', 'Mango')
Apple

Important Points

  • Tuples are ordered.
  • Tuples are immutable (cannot be changed).
  • Duplicates are allowed.
