Python Variables

Variables are used to store data values in Python. A variable is like a container that holds information.

Creating Variables

In Python, you don't need to declare the type of a variable. Python automatically understands the data type.

Example

name = "Aniruddh"
age = 17

print(name)
print(age)

Output

Aniruddh
17

Rules for Python Variables

  • A variable name must start with a letter or underscore (_)
  • A variable name cannot start with a number
  • Variable names are case-sensitive
  • Spaces are not allowed in variable names

Multiple Variables

Python allows you to assign values to multiple variables in one line. 

x, y, z = 10, 20, 30

print(x)
print(y)
print(z)

Output

10
20
30
Note: Python variables are created when you assign a value to them.
